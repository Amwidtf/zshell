# 隐私政策（Privacy Policy）

最后更新：2026-10-08 · 适用版本：v0.0.1-alpha 及之后版本

ZShell 的隐私设计只有一条原则：**零收集**。本软件没有自建服务器、没有账号体系、没有崩溃收集 SDK、没有广告和分析组件。你能看到的每一个功能都在你的设备上完成。

## 1. 我们收集哪些个人信息

**无。** 本软件不向开发者或任何第三方传输、上报任何个人信息或使用数据。

## 2. 本地存储的数据（永不离开你的设备）

| 数据 | 内容 | 存储方式 |
|---|---|---|
| 机器列表 | 已配对桌面端的名称、地址、凭据（sid/hash）、收藏与排序 | AES 加密（MMKV），密钥由 Android Keystore 托管 |
| 应用锁设置 | 锁定方式、PBKDF2 验证器（盐 + 哈希，**不存明文密码/图案**） | 同上 |
| 诊断状态 | 仅存在于内存（重启即消失），不落盘 | — |

卸载应用或清除应用数据即可**彻底删除**以上全部数据。

## 3. 权限用途说明

| 权限 | 用途 | 说明 |
|---|---|---|
| 相机（CAMERA） | 扫描桌面端配对二维码 | 仅取景识别，不拍照、不录像、不保存任何图像 |
| 生物识别（USE_BIOMETIC） | 应用锁的指纹 / 人脸验证 | 仅调用系统本机验证，本软件不接触、不存储生物特征数据 |
| 照片访问 | 「从相册选择二维码图片」功能 | 仅在你主动选图时读取所选单张图片，识别完成即丢弃，不访问相册其他内容 |
| 网络（INTERNET） | 连接你自己的桌面端配对地址与官方远程控制台 | 你发起的连接，本软件无自建服务器。此外仅当你主动「检查更新」时访问 GitHub（api.github.com 及其下载服务） |
| 安装应用（REQUEST_INSTALL_PACKAGES） | 应用内更新 | 下载完成后交系统安装器安装，是否安装始终由你确认 |

## 4. 第三方组件

以下开源组件均为**本地功能实现**，不进行任何数据上报：

| 组件 | 用途 |
|---|---|
| react-native / react-native-webview | 应用框架与控制台容器 |
| react-native-camera-kit | 相机扫码 |
| react-native-image-picker | 相册选图 |
| react-native-mmkv-storage | 加密本地存储 |
| react-native-biometrics | 系统生物识别 |
| jsQR / jpeg-js / pako | 二维码图片识别（纯本地解码） |

应用内更新下载使用系统自带的 DownloadManager（系统组件，非第三方库）。

## 5. 数据安全

- 配对凭据使用 AES 加密存储，密钥存放于 Android Keystore，无法在未 root 且未解锁的设备上被读取；
- 应用锁（生物识别 / 图案 / 密码）防止他人打开本应用查看或使用已保存的凭据；
- 凭据验证使用 PBKDF2-HMAC-SHA256（20000 次迭代 + 随机盐），不存储明文；
- 请知悉：远程会话内容经由官方中继服务传输（见 [DISCLAIMER.md](./DISCLAIMER.md) 第 5 条），该环节不在本软件控制范围内。

## 6. 未成年人

本软件面向开发者群体，不建议未成年人使用。

## 7. 政策变更

政策如有重大变更，将随版本发布在本文件更新。继续使用即表示接受更新后的政策。

## 8. 联系我们

对本政策有疑问，或需行使个人信息权利，请通过仓库 Issue 或 SECURITY.md 中的渠道联系。
